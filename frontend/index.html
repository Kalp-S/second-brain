Engineering Architecture Invariants
Reciprocal Rank Fusion (RRF)
In-memory ranking merger ($k=60$). Eliminates calibration error between unbounded BM25 scores and bounded cosine distance vectors.
Cross-Encoder Reranking
ONNX cross-attention transformer (`FlashRank`). Filters out semantically vague bi-encoder candidates, pruning noise before LLM prompt injection.
Parent-Child Hierarchy
Small child chunks (~300 chars) match query vectors with surgical precision; parent sections (~1200 chars) supply complete context to the LLM.
